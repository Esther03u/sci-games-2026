ตัดสินใจแล้ว (10 ต.ค.): เรียงแท่งตามสีคงที่ · ยาว ~40 วิ · ป้าย +คะแนน เด้งทีละรายการ ทุกสีพร้อมกัน

เป้า: เฉลยคะแนนรวม 4 สี วันที่ 11 ต.ค. 16:30 ให้ลุ้น — โพเดียมเริ่มสูงเท่ากันทุกสี ตอนเฉลยแท่งค่อย ๆ สูงขึ้นทีละรายการ มีป้าย "+คะแนน" เด้งบอกว่ามาจากรายการไหน และเมื่อจบแล้วกด/ชี้ดูที่มาของคะแนนแต่ละสีได้

**ข้อห้าม:** ห้ามเปิดคะแนนจริงก่อนเวลา — ไม่แตะ `app_settings.podium_countdown` บน production · ทดสอบด้วย **ข้อมูลจำลอง** เท่านั้น

## 0. ของเดิมที่ใช้ต่อ (ไม่เปลี่ยน)

- คะแนนรวมไม่อยู่ในหน้าเว็บก่อนเฉลย (`lib/queries/placements` → `revealed`) และ `/api/standings` ส่ง `standings`/`points` เฉพาะหลังแอดมินเปิด — **คงไว้ทั้งหมด**
- สูตร: แต่ละรายการ (กีฬา × ประเภท, 11 รายการ) ที่ 1–4 ได้ 30/25/20/15 (ตั้งได้ในแอดมิน) → คะแนนดิบรวม → `× 100 ÷ 330` (ทศนิยม 2) · เสมอ → ดูถ้วยที่ 1 → 2 → 3 (`lib/placements.js`)
- การเปิดเฉลย: แอดมินกด เฉลยทันที / เร่งเวลาแล้วเฉลย / ถึงเวลา `target_time` → ผู้ชมรู้ภายใน ~8–13 วิ (poll)

## 2. ลำดับแอนิเมชันตอนเฉลย (~40 วินาที — ผู้ใช้เลือก 10 ต.ค.)

1. **เริ่ม (2 วิ):** แถบ "กำลังเฉลยคะแนน…" แท่งสั่นเล็กน้อย
2. **ทีละรายการ ×11 (~3.2 วิ/รายการ: ขึ้นชื่อรายการ 0.8 วิ → แท่งโต + ป้ายเด้งของทุกสีพร้อมกัน 1.6 วิ → ค้าง 0.8 วิ)** เรียงตามสูจิบัตร (ฟุตซอล ชาย → … → เปตอง คู่ผสม):
   - ป้ายด้านบนแสดง "รายการ 4/11 · วอลเลย์บอล ชาย"
   - ทุกสีที่ได้อันดับในรายการนั้น แท่งสูงขึ้นพร้อมกันตามคะแนนที่ได้ และมีป้ายเด้ง **"+30 🥇 วอลเลย์บอล ชาย"** ลอยขึ้นแล้วจางหาย (hit pop, ขนาด/สีต่างกันตามอันดับ)
   - ตัวเลขบนแท่งนับขึ้นเป็นคะแนนดิบสะสม
3. **สรุป (3 วิ):** ตัวเลขเปลี่ยนจากคะแนนดิบเป็น **คะแนนเต็ม 100** (×100÷330) · ป้ายอันดับ 1–4 ขึ้นบนหัวแท่ง · มงกุฎ + Confetti ให้ที่ 1 · ถ้าเสมอแสดง "ตัดสินด้วยถ้วยชนะเลิศ"
- ความสูง: ฐานเท่ากัน (สูง 35%) + ส่วนที่โตตามคะแนนดิบ (สูงสุด = 330) → ความต่างเห็นชัดแต่ไม่มีแท่งไหนหายไป
- คนที่เปิดหน้าหลังเฉลยไปแล้ว: เห็นผลสุดท้ายทันที + ปุ่ม **"▶ ดูการเฉลยอีกครั้ง"**
- `prefers-reduced-motion`: ข้ามแอนิเมชัน แสดงผลสุดท้าย
- รายการที่ยังแข่งไม่จบตอนเฉลย: นับเฉพาะอันดับที่มีผลแล้ว (เหมือนสูตรปัจจุบัน) และระบุ "x/11 รายการ"

## 3. ดูที่มาของคะแนน (หลังเฉลยจบ)

- ชี้ (desktop) = tooltip สั้น: "ที่ 1 ×3 · ที่ 2 ×4 … ดิบ 270 → 81.82"
- กด/แตะแท่ง (ทุกอุปกรณ์) = แผงรายละเอียดของสีนั้น:

| รายการ | อันดับ | คะแนน |
|---|---|---|
| ฟุตซอล ชาย | 🥇 ที่ 1 | 30 |
| ฟุตซอล หญิง | 🥉 ที่ 3 | 20 |
| … | | |
| **รวมคะแนนดิบ** | | **270 / 330** |
| **คะแนนรวม** | 270 × 100 ÷ 330 | **81.82** |

  พร้อมจำนวนถ้วย 🥇🥈🥉 และหมายเหตุเกณฑ์ตัดสินเมื่อเสมอ · ปิดด้วย Esc / กดนอกแผง · ใช้คีย์บอร์ดได้ (แท่งเป็นปุ่ม)

## 5. การทดสอบ (ไม่เปิดคะแนนจริง)

1. Unit: timeline (ลำดับรายการ, คะแนนสะสม, เสมอ, รายการไม่ครบ, คะแนนตั้งเอง), breakdown (สูตร ×100÷330 ตรงกับ `computeStandings`)
2. ข้อมูลจำลอง: ชุดสมมติ 11 รายการ (มีเคสเสมอ) ใช้ทั้งในแอดมินและ Playwright
3. Playwright บนเครื่อง: เล่นจำลองจนจบ → ตรวจความสูงสุดท้าย/อันดับ/ตัวเลข → กดแท่งแต่ละสีดูตาราง → เล่นซ้ำ → มือถือ/คีย์บอร์ด/reduced-motion · หน้าแรกจริงต้องยังเป็น "?" และนับถอยหลังอยู่ (ไม่มีคะแนนใน HTML / ไม่มี `standings` จาก API)
4. Production หลัง deploy (อ่านอย่างเดียว): หน้าแรกยังนับถอยหลัง, `/api/standings` ยังตอบ `revealed: false`
5. ซ้อมจริงก่อนงาน: แอดมินกด "จำลองการเฉลย" ในหน้าตั้งค่าให้เห็นของจริงบนจอใหญ่
